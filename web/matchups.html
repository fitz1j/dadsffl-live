Preseason Simulation

Twelve exhibition matchups scored off real ESPN preseason box scores, using the league's own scoring rules.

Every rostered player counts. Roster rules are switched off for this exercise — all 24 drafted players score, with no 11-slot starting lineup, no flex eligibility and no bench. Points come from the archived ESPN box scores for NFL preseason weeks 1–3 (the Hall of Fame game is not part of any matchup), scored with the league's bracket rules for passing, rushing, receiving, kicking and IDP. No negative points anywhere.
